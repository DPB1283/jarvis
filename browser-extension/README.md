# Jarvis browser extension

1. Open `chrome://extensions` in Chrome or `edge://extensions` in Edge.
2. Turn on Developer mode.
3. Select Load unpacked and choose this `browser-extension` folder.
4. Open Jarvis Settings → Browser, then use the extension button to enter the port and pairing code.

Jarvis keeps its work in its own collapsed tab group. The extension reconnects after browser or Jarvis restarts.
